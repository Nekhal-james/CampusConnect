# CampusConnect

A desktop application for college event management and community engagement.

## 🧩 Features

- User Authentication (Login/Register)
- Role-Based Access (Admin, Organizer, Student)
- Event Management (Create, View, Delete)
- Event Registration System
- Feedback Submission
- Notification Reminders
- Event Archive

## 🧱 Tech Stack

- **Language**: Java 17+
- **UI**: Swing (MVC)
- **Database**: SQLite (JDBC)
- **Build Tool**: Maven
- **Testing**: JUnit 5
